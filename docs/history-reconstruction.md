# About the commit history

The plugin was built with AI assistance before this repository was published. On 2026-10-04 the finished code
was split into small commits (scaffold, rendering, editor integration, Swing glow, settings, themes, docs) so
the history is readable. Commit dates in that range were assigned during the split and don't reflect when the
work was done. Commits keep the AI co-author trailer.

On 2026-10-05 the project was renamed from "IDE Synthwave" to **Neon Glow**: plugin ID and package
`info.chrzanowski.neonglow`, Gradle project `neon-glow`, theme and settings identifiers. Behaviour was unchanged.

Verification results for both steps are in [theme-quality.md](theme-quality.md).
